# BOCA (博卡) - 中国动漫 MEME 社区

BOCA（Book of Chinese Anime / 博卡）是首个致力于中国动漫 MEME 文化传播的 Web3 项目。我们致力于通过区块链技术和 MEME 文化，让中国动漫 IP 焕发新生，打造充满趣味性的去中心化国漫社区。

## 🌟 核心功能

- 🎭 **MEME 创作**: 让每个人都能参与国漫 MEME 创作
- 🎯 **社区驱动**: 通过 $BOCA 代币激励优质 MEME 创作者
- 🔮 **文化传播**: 用 MEME 让国漫文化更有趣、更易传播
- 🤝 **社区共创**: 社区投票选出最佳 MEME 作品

## 🚀 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看网站。

## 📦 技术架构

```
boca-website/
├── app/
│   ├── layout.tsx          # 全局布局
│   ├── page.tsx           # 首页
│   └── metadata.ts        # SEO 元数据配置
├── components/
│   ├── sections/          # 页面分区组件
│   │   ├── Hero.tsx      # MEME 首屏展示
│   │   ├── Vision.tsx    # 项目愿景
│   │   ├── Memes.tsx     # MEME 展示墙
│   │   └── Footer.tsx    # 底部声明
│   ├── ui/               # 通用UI组件
│   └── animations/       # 动画组件
├── lib/
│   ├── fonts.ts          # 字体配置
│   └── constants.ts      # 常量定义
└── public/
    ├── images/          # 图片资源
    └── locales/         # 国际化文案
```
